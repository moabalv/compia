## 🚀 Tecnologias Utilizadas

- **Core:** React 18+, Vite

- **Gerenciamento de Estado:** Zustand
- **Formulários:** React Hook Form
- **API Mocking:** Mock Service Worker (MSW)
- **Ícones/QR Code:** `qrcode.react`

## ⚙️ Como Rodar o Projeto

Siga os passos abaixo para configurar e executar o projeto em seu ambiente local.

### Pré-requisitos

- **Node.js**: Versão 18.x ou superior.
- **npm** (ou um gerenciador de pacotes compatível como Yarn ou pnpm).

### Passos para Instalação

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/compia-ecommerce.git](https://github.com/seu-usuario/compia-ecommerce.git)
    ```
    *(Substitua a URL pelo link do seu repositório)*

2.  **Navegue até a pasta do projeto:**
    ```bash
    cd compia-ecommerce
    ```

3.  **Instale todas as dependências:**
    ```bash
    npm install
    ```

4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

Após executar o último comando, o servidor de desenvolvimento do Vite será iniciado. Você poderá acessar a aplicação no seu navegador, geralmente no endereço **http://localhost:5173**.
